# v0.2-beta

## 2026-10-27

### Version v0.2-beta

#### Changed
- The app is now **v0.2-beta** (`VERSION_LABEL` in `backend/repolens/__init__.py`, `0.2.0b0` for packaging, `0.2.0-beta` in `frontend/package.json`). It shows in the sidebar and on the sign-in, About and Settings pages, and `GET /healthz` returns it. `tests/test_version.py` checks that every place agrees.
- This version starts a new changelog file, `changelog/v0.2-beta.md`. Everything up to and including the role review, the answer checks and the joined-name search is in `changelog/v0.1-beta.md`.
- The MCP handshake now reports the app's own version (it had a fixed `0.1.0` that nobody kept in step).

#### Upgrade notes
- No database migration and no re-index. A release tag shaped `vMAJOR.MINOR.PATCH` is still needed to build images; none was created by this change.
