# Ask: a chat with your knowledge base

### Added
- **Ask** page (sidebar item and a floating **Ask** button on every other page): a chat over the repositories, documents, wiki and graph you can see, with cited sources that open in the wiki or the graph.
- Chat history grouped by date and searchable; **rename**, **edit a question** (later messages are removed and it is answered again), **archive**/restore and **delete** (with confirmation) a chat.
- Scope a chat to one repository or document collection; follow-up questions use the earlier turns.
- **Attach a `.txt` or `.log` file** for debugging (only those types, secrets masked, up to 200,000 characters); its error lines, stack frames and code names are used to search your code and docs.
- **Allow fallback knowledge** (off by default, needs a connected model, always labelled "Not from your documents").
- `GET/POST /api/chats`, `GET/PATCH/DELETE /api/chats/{id}`, `POST /api/chats/{id}/messages`, `PUT /api/chats/{id}/messages/{id}`; migration 0021; policy action `chat.write` (viewers may chat); chat messages use the tighter rate limit.
- A "Private chats" row in the control status table on the Security page.

### Security
- A chat is visible only to its owner (admins, other workspaces and access tokens are refused); attachments and sources are treated as untrusted data in the prompt; stored sources are filtered by the viewer's current access.
