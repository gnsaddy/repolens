# Nightly database backups and a restore guide

### Added
- Kubernetes: a nightly `CronJob` (`deploy/k8s/backup.yaml`) writes a compressed PostgreSQL dump to its own volume, checks it reads back, and keeps 14 days. A network policy lets only it and the API reach the database.
- `docs/operations.md`: what to back up (and why `REPOLENS_SECRET_KEY` must be kept), restore steps, upgrade advice. `make backup` and `make restore` for Docker Compose.

### Upgrade notes
- Apply the updated manifests (`kubectl apply -k deploy/k8s`). Copy dumps off the cluster: a backup on the database's own disk does not survive losing that disk.
